# Saleel KM — Product Design Portfolio

Static, single-page portfolio. No build step.

## Publish on GitHub Pages
1. Create a new repository (e.g. `portfolio`) and upload everything in this folder: `index.html`, the `img/` folder and `.nojekyll`.
2. Go to **Settings → Pages**, set **Source** to *Deploy from a branch*, branch `main`, folder `/ (root)`, and save.
3. The site goes live at `https://<your-username>.github.io/<repo-name>/` within a minute or two.

To use `https://<your-username>.github.io/` instead, name the repository `<your-username>.github.io`.
